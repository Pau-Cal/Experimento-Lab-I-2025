# Glosario inicial

## Estadística e inferencia

- **Variable aleatoria**: cantidad numérica asociada al resultado de un fenómeno incierto.
- **Intervalo de confianza**: rango plausible para un parámetro poblacional bajo un nivel de confianza dado.
- **P-valor**: medida de compatibilidad entre los datos observados y la hipótesis nula.

## Programación para ciencia de datos

- **Pipeline**: secuencia reproducible de pasos de procesamiento y análisis.
- **Dataframe**: estructura tabular usada para manipular datos.
- **Reproducibilidad**: capacidad de regenerar el mismo resultado con el mismo proceso y datos.

## Aprendizaje automático

- **Sobreajuste**: situación en la que un modelo aprende ruido del entrenamiento y generaliza mal.
- **Validación cruzada**: método para estimar el desempeño fuera de muestra.
- **Interpretabilidad**: facilidad para entender cómo un modelo llega a una predicción.

## Visualización y comunicación

- **Narrativa visual**: organización de gráficos y mensajes para comunicar un hallazgo.
- **Carga cognitiva**: esfuerzo mental necesario para interpretar una visualización.

## Optimización y experimentación

- **A/B testing**: experimento controlado para comparar dos variantes.
- **Métrica primaria**: indicador principal usado para evaluar el éxito de una intervención.

## Proyecto aplicado o tesis

- **Pregunta de investigación**: formulación central que guía el proyecto.
- **Criterio de éxito**: condición observable que permite evaluar si el proyecto cumplió su objetivo.
